# 11:11 — موقع رومانسي تفاعلي

تجربة صغيرة بتفتح بقفل، وبعدين جواب طاير لازم تمسكيه، وفي الآخر رسالة.

## الملفات

```
11-11-website/
├── index.html        الهيكل (الشاشات الثلاث)
├── style.css         الألوان، الحركات، الـ 3D، التجاوب مع الموبايل
├── script.js         الباسورد، منطق الـ 3 لمسات، الرسالة، خلفية Three.js
├── assets/
│   ├── images/       (فاضية — مفيش صور مطلوبة)
│   ├── textures/     (فاضية — ورق الجواب متعمل بـ CSS/SVG)
│   └── sounds/       (فاضية — مفيش أصوات)
└── README.md
```

## التشغيل

افتحي `index.html` في المتصفح مباشرة، أو ارفعي المجلد كله على GitHub Pages.
كل المسارات نسبية، ومفيش backend ولا أي خدمة مدفوعة.

## رفع على GitHub Pages

1. اعملي repository جديد على GitHub.
2. ارفعي محتويات المجلد (مش المجلد نفسه) في الـ root.
3. من **Settings → Pages** اختاري `Deploy from a branch` → `main` → `/ (root)`.
4. الموقع هيبقى على `https://<username>.github.io/<repo>/`.

## تعديل الرسالة

الرسالة موجودة في `index.html` داخل قسم `screen-message`.
كل فقرة في `<p>` لوحدها، وتقدري تعدّلي أو تضيفي فقرات عادي.

## الموسيقى

1. حطي ملف الأغنية بصيغة `mp3` في المجلد `assets/sounds/` باسم `song.mp3`.
   (لازم تكوني مالكة الأغنية أو معاكي حق استخدامها.)
   لو اسم الملف مختلف، غيّريه في أول `script.js` عند `MUSIC_SRC`.
2. الأغنية بتبدأ مع آخر لمسة على الجواب (اللمسة الثالثة)، وبتزيد صوتها تدريجياً مع الفلاش.
3. زرار ♪ في الركن بيشغّل أو يوقف الموسيقى، وبيظهر بس لما الأغنية تبدأ.
4. لو الملف مش موجود، الزرار بيفضل مخفي والموقع بيكمل عادي.

ملحوظة: المتصفحات بتمنع الصوت يشتغل من غير ضغطة من المستخدم، فالأغنية بتبدأ مع اللمسة نفسها.
